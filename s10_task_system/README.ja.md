# s10: タスクシステム

[English](README.md) · [中文](README.zh.md) · [日本語](README.ja.md)

[s09: メモリシステム](../s09_memory/) → **s10** → [s11: バックグラウンドタスク](../s11_background_tasks/)

> ファイルに支えられたグラフと原子的なクレームを、全エージェントで共有する。

---

## 課題

複数のエージェントには、クラッシュに耐え、二重割り当てを起こさない作業状態が要る。メモリ上のリストではどちらも満たせない。

## 仕組み

1. タスクごとに JSON ファイルを1つ置き、原子的に作成する。
2. blockedBy で依存を表し、解消するまでクレームを拒否する。
3. ファイルロックの下でクレームし、owner ごとに進行中1件に限る。

## コードマップ

| ファイル | 役割 |
|---|---|
| `s10_task_system/main.go` | 本章の入口。この仕組みを1つのループに接続する。 |
| `internal/harness/tasks.go` | 全章で共有する実装。 |
| `.tasks/` | 本章が書き出す状態。 |

## 実行

```bash
go run ./s10_task_system
```

初回実行前に .env.example を .env にコピーし、いずれかのプロバイダーを設定してください。認証情報がなくても --help は動きます。

## 試してみる

- 2つのタスクを作り、2つ目を1つ目に依存させる。
- 同じ owner で両方をクレームし、エラーを読む。
