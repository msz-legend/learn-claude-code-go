## 課題

1つのエージェントは複数の独立した枝を同時に探索できない。助っ人を起動するのは簡単だが、衝突せずに協調させるのが難しい。

## 仕組み

1. 各メンバーに名前、役割、独自ループ、任意のワークツリーを与える。
2. タスクボードを共有し、原子的にクレームして同じタスクの二重取得を防ぐ。
3. 追記型メールボックスとカーソルで、メッセージを1回だけ届ける。

## コードマップ

| File | Role |
|---|---|
| `s13_agent_teams/main.go` | 本章の入口。この仕組みを1つのループに接続する。 |
| `internal/harness/team.go`, `internal/harness/tasks.go` | 全章で共有する実装。 |
| `.team/` | 本章が書き出す状態。 |

## 実行

```bash
go run ./s13_agent_teams
```

初回実行前に .env.example を .env にコピーし、いずれかのプロバイダーを設定してください。認証情報がなくても --help は動きます。

## 試してみる

- 小さなタスクにメンバーを1人起動し、lead の受信箱を読む。
- メンバーが作業中に /team を実行する。
