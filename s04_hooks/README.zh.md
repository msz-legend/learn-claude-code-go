## 问题

为了加一条防护或日志就改循环，会让每个新关注点都变成核心改动。钩子给这些位置一个稳定的名字。

## 工作机制

1. 在用户输入、工具执行前、执行后和停止时运行钩子。
2. 让工具前钩子带理由阻止调用，模型能读到这条理由。
3. 把工具后的输出依次传给每个钩子，后面的钩子能看到前面的修改。

## 代码地图

| 文件 | 作用 |
|---|---|
| `s04_hooks/main.go` | 本章入口：把这个机制接进同一个循环。 |
| `internal/harness/hooks.go` | 每章共用的实现。 |

## 运行

```bash
go run ./s04_hooks
```

首次运行前把 .env.example 复制为 .env，填入一个提供方的配置。没有密钥时 --help 仍可使用。

## 动手试试

- 让它写 .env，观察密钥钩子拦下调用。
- 加一个停止钩子，打印消息数量。
