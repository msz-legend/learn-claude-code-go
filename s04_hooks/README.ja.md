## 課題

ガードやログのたびにループを編集すると、新しい関心事がすべてコアの変更になる。フックは同じ場所に安定した名前を与える。

## 仕組み

1. ユーザー入力時、ツール前、ツール後、停止時にフックを実行する。
2. ツール前フックは理由付きでブロックし、モデルがそれを読めるようにする。
3. ツール後の出力を各フックに順に渡し、前の変更を次が見られるようにする。

## コードマップ

| ファイル | 役割 |
|---|---|
| `s04_hooks/main.go` | 本章の入口。この仕組みを1つのループに接続する。 |
| `internal/harness/hooks.go` | 全章で共有する実装。 |

## 実行

```bash
go run ./s04_hooks
```

初回実行前に .env.example を .env にコピーし、いずれかのプロバイダーを設定してください。認証情報がなくても --help は動きます。

## 試してみる

- .env を書かせて、シークレットフックが止めるのを見る。
- 停止フックを追加してメッセージ数を表示する。
