## 问题

让执行者自己决定何时完成，是找错了裁判。自信的总结不是证据，提前停下才是默认的失败。

## 工作机制

1. 让执行者像平常一样结束回合。
2. 把记录交给一个没有工具、标准严格的评估者。
3. 接受、带理由驳回，或判定目标不可能；同时限制评估次数。

## 代码地图

## 运行

```bash
go run ./s17_goal_loop
```

首次运行前把 .env.example 复制为 .env，填入一个提供方的配置。没有密钥时 --help 仍可使用。

## 动手试试

- 用一个需要真实命令的目标运行，例如让测试通过。
- 给一个不可能的目标，观察评估者结束循环。
