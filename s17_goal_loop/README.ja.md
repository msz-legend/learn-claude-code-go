[English](README.md) · [中文](README.zh.md) · [日本語](README.ja.md)

[s16: ワークフローランタイム](../s16_workflow_runtime/) → **s17** → 終点

> 作業が本当に完了したかを、独立した評価者が決める。

---

## 課題

作業者が自分の完了を決めるのは、審判を間違えている。自信のある要約は証拠ではなく、早すぎる停止が既定の失敗だ。

## 仕組み

1. 作業者はいつも通りターンを終える。
2. ツールを持たない厳格な評価者に記録を送る。
3. 承認、理由付きの差し戻し、不可能判定を行い、評価回数に上限を置く。

## コードマップ

| ファイル | 役割 |
|---|---|
| `s17_goal_loop/main.go` | 本章の入口。この仕組みを1つのループに接続する。 |
| `internal/harness/goal.go`, `internal/harness/stopgate.go`, `internal/harness/loop.go` | 全章で共有する実装。 |

## 実行

```bash
go run ./s17_goal_loop
```

初回実行前に .env.example を .env にコピーし、いずれかのプロバイダーを設定してください。認証情報がなくても --help は動きます。

## 試してみる

- テストを通すなど、実際のコマンドが必要な目標で実行する。
- 不可能な目標を与え、評価者がループを止めるのを見る。
