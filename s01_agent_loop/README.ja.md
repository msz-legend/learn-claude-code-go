# s01: エージェントループ

[English](README.md) · [中文](README.zh.md) · [日本語](README.ja.md)

開始 → **s01** → [s02: ツール使用](../s02_tool_use/)

> 1つのループと1つのシェルツールだけで、チャットモデルはエージェントになる。

---

## 課題

モデルはシェルコマンドを提案できても、出力したところで止まる。ハーネスがなければ、人間が毎回コマンドを実行して結果を貼り戻すことになる。

## 仕組み

1. 会話とツール定義をまとめてモデルに送る。
2. アシスタントのブロックを追加し、tool_use がなければテキストを返す。
3. 各 tool_use を実行し、呼び出しごとに tool_result を追加してループする。

## コードマップ

| ファイル | 役割 |
|---|---|
| `s01_agent_loop/main.go` | 本章の入口。この仕組みを1つのループに接続する。 |
| `internal/harness/loop.go`, `internal/harness/cli.go`, `internal/harness/workspace.go` | 全章で共有する実装。 |

## 実行

```bash
go run ./s01_agent_loop
```

初回実行前に .env.example を .env にコピーし、いずれかのプロバイダーを設定してください。認証情報がなくても --help は動きます。

## 試してみる

- ワークスペースを一覧させ、そのあと最大のファイルを読ませる。
- ツール不要の質問をして、1ターンで終わることを確認する。
