## 課題

今すぐでなく後で行う作業がある。1つの会話の中のタイマーは、会話が終われば消える。

## 仕組み

1. 5フィールド式を解析し、範囲を検証する。
2. ジョブを永続化し、最終実行キーを記録して再起動時の重複を防ぐ。
3. ポーリングして期限到来分をキューに入れ、次の要求前に注入する。

## コードマップ

| ファイル | 役割 |
|---|---|
| `s12_cron_scheduler/main.go` | 本章の入口。この仕組みを1つのループに接続する。 |
| `internal/harness/cron.go` | 全章で共有する実装。 |
| `.cron/` | 本章が書き出す状態。 |

## 実行

```bash
go run ./s12_cron_scheduler
```

初回実行前に .env.example を .env にコピーし、いずれかのプロバイダーを設定してください。認証情報がなくても --help は動きます。

## 試してみる

- 1分後の単発プロンプトを予約して待つ。
- プロセスを再起動し、/cron でジョブが残っていることを確認する。
