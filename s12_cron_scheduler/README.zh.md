> 持久化未来提示，并在进程运行期间把它们变成新的对话轮次。

---

## 问题

有些工作应该稍后做，而不是现在。单个对话里的计时器会随对话结束而消失。

## 工作机制

1. 解析五段式表达式并校验取值范围。
2. 持久化任务并记录上次运行键，重启后不会重复触发。
3. 轮询、排队到期的提示，在下次请求前注入。

## 代码地图

| 文件 | 作用 |
|---|---|
| `s12_cron_scheduler/main.go` | 本章入口：把这个机制接进同一个循环。 |
| `internal/harness/cron.go` | 每章共用的实现。 |
| `.cron/` | 本章写入的状态。 |

## 运行

```bash
go run ./s12_cron_scheduler
```

首次运行前把 .env.example 复制为 .env，填入一个提供方的配置。没有密钥时 --help 仍可使用。

## 动手试试

- 安排一分钟后的单次提示，然后等待。
- 重启进程，运行 /cron 确认任务还在。
