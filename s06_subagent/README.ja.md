> 雑音の多い調査に専用のコンテキストを与え、結論だけを持ち帰る。

---

## 課題

ファイルを読むたび、行き止まりにぶつかるたびに親のコンテキストは埋まる。子エージェントはその雑音を吸収できるが、結果が短い要約で戻る場合に限る。

## 仕組み

1. 新しいメッセージ列と明確な依頼文で子を起動する。
2. 親の全履歴ではなく、必要なツールだけを渡す。
3. 最終テキストだけを返し、子のターン数に上限を置く。

## コードマップ

| File | Role |
|---|---|
| `s06_subagent/main.go` | 本章の入口。この仕組みを1つのループに接続する。 |
| `internal/harness/agents.go`, `internal/harness/loop.go` | 全章で共有する実装。 |

## 実行

```bash
go run ./s06_subagent
```

初回実行前に .env.example を .env にコピーし、いずれかのプロバイダーを設定してください。認証情報がなくても --help は動きます。

## 試してみる

- リポジトリ調査を任せ、インラインでやる場合とコンテキスト量を比べる。
- SUBAGENT_MAX_TURNS を下げて、早く止まるのを見る。
